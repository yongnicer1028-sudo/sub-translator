# 영상 실시간 번역 자막 앱 (안드로이드, 나만 쓰는 버전)

유튜브/틱톡 같은 영상 앱에서 나오는 중국어·일본어·영어 소리를 실시간으로 인식해서,
화면 위에 작은 자막창으로 한국어 번역을 띄워주는 개인용 안드로이드 앱이에요.
이어폰을 껴도 작동해요 (마이크가 아니라 폰 내부 소리를 직접 가져오는 방식이에요).

코딩을 몰라도 아래 순서대로만 따라 하면 설치 파일(APK)을 받아서 폰에 깔 수 있어요.

---

## 0단계. 전체 흐름 한눈에 보기

1. 이 폴더 전체를 깃허브(GitHub)에 올린다
2. 깃허브가 자동으로 컴파일해서 설치 파일(APK)을 만들어준다 (5분 정도 걸림)
3. 그 설치 파일을 폰으로 옮겨서 설치한다
4. 앱을 열고 언어를 선택한 뒤 '번역 시작'을 누른다 (API 키 필요 없음, 완전 무료)

---

## 1단계. 깃허브에 코드 올리기 (드래그 앤 드롭만 하면 됨)

1. [github.com](https://github.com) 에 로그인
2. 오른쪽 위 `+` 버튼 → `New repository` 클릭
3. Repository name에 아무 이름이나 입력 (예: `sub-translator`)
4. Public/Private 아무거나 선택하고 `Create repository` 클릭
5. 저장소가 생기면 `uploading an existing file` 이라는 파란 글씨 링크를 클릭
   (안 보이면 `Add file` → `Upload files` 버튼을 눌러도 돼요)
6. 이 프로젝트 폴더(`VideoSubTranslator`) **안에 있는 모든 파일과 폴더**를 통째로
   그 업로드 화면에 마우스로 끌어다 놓기 (드래그 앤 드롭)
   - `.github` 폴더도 반드시 같이 올려야 해요! (숨김 폴더처럼 보여도 꼭 포함)
7. 아래로 내려서 `Commit changes` 버튼 클릭

업로드가 끝나면 자동으로 빌드가 시작돼요 (다음 단계).

---

## 2단계. 자동으로 만들어진 설치 파일(APK) 받기

1. 저장소 페이지 상단 메뉴에서 `Actions` 탭 클릭
2. `Build APK` 라는 이름의 작업이 노란 점(진행 중) 또는 초록 체크(완료)로 떠 있을 거예요.
   완료될 때까지 3~5분 기다렸다가 그 항목을 클릭
3. 페이지 맨 아래 `Artifacts` 영역에 `app-debug-apk`가 보이면 클릭해서 다운로드
   (압축파일(zip)로 받아지는데, 압축을 풀면 안에 `app-debug.apk` 파일이 있어요)

> 만약 여기서 빨간 X(실패)가 뜨면, 당황하지 말고 그 항목을 클릭해서 나오는
> 빨간 글씨 에러 메시지를 캡처해서 저한테 보여주세요. 바로 고쳐드릴게요.

---

## 3단계. 폰에 설치하기

1. 방금 받은 `app-debug.apk` 파일을 태블릿/폰으로 옮기기 (카카오톡 나에게 보내기, 이메일, 구글 드라이브 등 아무 방법이나 편한 걸로)
2. 폰에서 그 파일을 눌러서 실행
3. "출처를 알 수 없는 앱" 관련 경고가 뜨면 → 설정으로 이동해서 **이 설치만 허용** 체크 후 뒤로 가서 다시 설치 진행
   (구글 플레이스토어 앱이 아니라서 나오는 정상적인 경고예요, 걱정 안 하셔도 돼요)
4. 설치 완료!

---

## 4단계. 앱 사용법

이제 API 키를 따로 발급받을 필요가 없어요. 음성인식(Vosk)과 번역(ML Kit) 둘 다
**완전 무료로 폰 안에서 처리**돼요. (언어를 처음 쓸 때만 인터넷으로 모델을 한 번씩 받아요)

1. 앱 실행
2. 영상 속 언어 선택 (중국어 / 일본어 / 영어)
3. `설정 저장` 클릭
4. `번역 시작` 클릭 → 이어서 뜨는 권한 화면 3개를 순서대로 모두 허용
   - 다른 앱 위에 표시 허용
   - 마이크(오디오) 권한 허용
   - 화면(소리) 캡처 허용 (화면은 안 보고 소리만 가져가요, 걱정 안 하셔도 돼요)
5. 화면 위 자막창에 "음성인식 모델을 내려받는 중…"이 보이면, 그 언어를 처음 쓰는 거예요.
   와이파이에서 한 번만 받으면(40~50MB 정도) 그 다음부터는 인터넷 없이도 바로 돼요.
6. 유튜브/틱톡 등 보고 싶은 영상 앱으로 이동해서 영상 재생
7. 화면 위에 작은 검은 자막창이 뜨고, 몇 초 간격으로 번역된 한국어가 표시돼요
8. 자막창은 손가락으로 눌러서 원하는 위치로 드래그 가능
9. 그만 쓸 때는 다시 이 앱으로 돌아와서 `번역 중지` 클릭

## 알아두면 좋은 점 (한계)

- **딜레이**: 소리를 3~4초 단위로 모아서 번역하기 때문에 실제 대사보다 3~4초 정도 늦게 자막이 떠요.
- **DRM(저작권 보호) 영상**: 넷플릭스처럼 보호가 걸린 영상은 안드로이드 시스템 자체가 소리 캡처를 막아요.
  유튜브/틱톡 같은 일반 영상은 대부분 문제없이 될 가능성이 높지만, 100% 보장은 아니에요.
- **문장이 뚝뚝 끊길 수 있음**: 지금은 그냥 3.5초마다 자르는 방식이라, 말하는 도중에 끊기면 번역이 어색할 수 있어요.
  실제로 써보시고 불편하면 말씀해주세요, 더 자연스럽게 자르는 방식으로 개선할 수 있어요.
- **번역 모델 최초 다운로드**: 언어를 처음 선택해서 쓸 때 딱 한 번, 인터넷으로 번역 모델을 받아요 (몇 초~수십 초).
  그 다음부터는 인터넷 없어도 번역 자체는 폰 안에서 처리돼요 (무료, 무제한).
- **음성인식 모델도 최초 한 번만 다운로드**: 언어별로 처음 쓸 때 딱 한 번, 인터넷으로 음성인식 모델을 받아요
  (40~50MB 정도라 와이파이를 추천해요). 그 다음부터는 인터넷 없이 폰 안에서 처리되고,
  **아무리 오래 써도 돈이 전혀 안 나가요** (예전처럼 매달 60분 무료 제한이나 분당 과금이 없어요).
- **음성인식 정확도**: 완전 무료 오프라인 엔진(Vosk)을 쓰기 때문에, 유료 클라우드 서비스보다
  인식 정확도가 조금 떨어질 수 있어요. 실제로 써보시고 많이 불편하면 말씀해주세요.

## 문제가 생기면

아래 내용을 캡처하거나 복사해서 알려주시면 바로 고쳐드릴게요.
- 깃허브 Actions 빌드가 실패했다면: 빨간 에러 로그 전체
- 앱에서 오류가 났다면: 몇 번째 단계에서 무슨 메시지가 떴는지
- 자막이 아예 안 뜬다면: 어떤 영상 앱에서 시도했는지, 언어 선택을 뭘로 했는지
